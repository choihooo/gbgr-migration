# Data Model: AverageGraphPannel UI 이관

## 1. 자세 그래프 포인트 집합

### 설명

서버가 반환하는 자세 점수 시계열 원본 데이터다. 날짜 또는 순서를 나타내는 키와 점수 값의 쌍으로 구성된다.

### 필드

| 필드 | 타입 | 설명 | 검증 규칙 |
|---|---|---|---|
| `points` | `Record<string, number>` | 기간별 원본 그래프 점수 맵 | 빈 객체일 수 있으나, 패널은 이 경우에도 대체 데이터를 생성해야 함 |

### 관계

- `자세 그래프 포인트 집합`은 `차트 데이터 항목` 목록으로 변환된다.
- 표시 기간이 `weekly`이면 최근 7개 항목만 사용하고, `monthly`이면 전체 항목을 사용한다.

## 2. 그래프 표시 기간

### 설명

사용자가 토글로 선택하는 표시 상태다. 데이터 범위와 스크롤 정책을 결정한다.

### 필드

| 필드 | 타입 | 설명 | 검증 규칙 |
|---|---|---|---|
| `activePeriod` | `weekly \| monthly` | 현재 선택된 그래프 기간 | 두 값 외 허용하지 않음 |

### 상태 전이

| 현재 상태 | 이벤트 | 다음 상태 | 기대 결과 |
|---|---|---|---|
| `weekly` | 월간 토글 선택 | `monthly` | 전체 구간 표시, 필요 시 가로 스크롤 활성화 |
| `monthly` | 주간 토글 선택 | `weekly` | 최근 7개 구간 표시, 가로 스크롤 비활성화 |

## 3. 차트 데이터 항목

### 설명

차트 컴포넌트가 직접 소비하는 정규화된 단일 데이터 항목이다.

### 필드

| 필드 | 타입 | 설명 | 검증 규칙 |
|---|---|---|---|
| `periodLabel` | `string` | x축에 표시할 순번 라벨 | 주간은 `1~7`, 월간은 `1~31` 범위를 기본으로 사용 |
| `score` | `number` | 표시 점수 | 기본 범위는 `0~100`, `0`은 대체 점수로 치환 가능 |

### 파생 규칙

- 원본 데이터가 비어 있으면 기간 길이에 맞는 임시 데이터 목록을 생성한다.
- 원본 점수가 `0`이면 시각 공백 방지를 위해 임시 점수로 치환한다.

## 4. 차트 표시 설정

### 설명

레거시와 동일한 시각 규칙을 재현하기 위한 렌더링 설정 묶음이다.

### 필드

| 필드 | 타입 | 설명 | 검증 규칙 |
|---|---|---|---|
| `maxDomain` | `number` | y축 최대값 | 항상 `100` 유지 |
| `yAxisTicks` | `number[]` | y축 눈금 | `[25, 50, 75, 100]` 유지 |
| `fillColor` | `string` | 면적 그래프 채움 색상 | CSS 변수 또는 폴백 값 사용 |
| `strokeColor` | `string` | 그래프 선 색상 | CSS 변수 또는 폴백 값 사용 |
| `gridColor` | `string` | 가로 그리드 색상 | CSS 변수 또는 폴백 값 사용 |

### 관계

- `차트 표시 설정`은 `그래프 표시 기간`과 무관하게 동일 형식을 유지한다.
- 테마 변경 시 색상 값만 재계산되고 구조와 축 규칙은 유지된다.
