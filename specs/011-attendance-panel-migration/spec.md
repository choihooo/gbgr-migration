# Feature Specification: 출석 현황 패널 이관 (AttendancePanel)

**Feature Branch**: `011-attendance-panel-migration`
**Created**: 2025-04-15
**Status**: Draft
**Input**: User description: "AttendacePanel ui 똑같이 레거시에서 마이그레이션으로 이관"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 월간 출석 캘린더 조회 (Priority: P1)

사용자가 메인 대시보드에서 출석 현황 패널을 확인하여, 이번 달 자신의 자세 교정 앱 사용 이력을 한눈에 파악한다. 각 날짜별로 사용 시간에 따라 노란색 원의 진하기가 다르게 표시되어, 꾸준한 사용 패턴을 시각적으로 확인할 수 있다.

**Why this priority**: 출석 현황 패널의 핵심 기능이며, 사용자에게 가장 먼저 보여지는 주요 정보이다.

**Independent Test**: 대시보드 진입 시 출석 현황 패널이 렌더링되고, 이번 달 캘린더가 7열 그리드로 표시되는지 확인. 오늘 날짜에 노란색 링 강조가 표시되는지, 데이터가 없는 날은 회색 원으로 표시되는지, 미래 날짜는 테두리만 있는 원으로 표시되는지 검증.

**Acceptance Scenarios**:

1. **Given** 사용자가 메인 대시보드에 접속함, **When** 출석 현황 패널이 렌더링됨, **Then** 이번 달 캘린더가 요일 헤더(일~토)와 함께 7열 그리드로 표시됨
2. **Given** 이번 달 출석 데이터가 존재함, **When** 캘린더가 표시됨, **Then** 사용 시간에 따라 5단계 노란색 원으로 각 날짜가 표시됨 (0~1시간: 가장 연함, 4시간 이상: 가장 진함)
3. **Given** 사용 기록이 없는 날이 존재함, **When** 캘린더가 표시됨, **Then** 해당 날짜는 회색(bg-grey-50) 원으로 표시됨
4. **Given** 오늘 날짜가 캘린더에 포함됨, **When** 캘린더가 표시됨, **Then** 오늘 날짜 원에 노란색 링(ring-yellow-500)이 강조됨
5. **Given** 오늘 이후의 미래 날짜가 존재함, **When** 캘린더가 표시됨, **Then** 미래 날짜는 테두리만 있는 투명 원으로 표시됨
6. **Given** 일요일 열이 캘린더에 표시됨, **When** 요일 헤더가 렌더링됨, **Then** 일요일 텍스트가 빨간색으로 표시됨

---

### User Story 2 - 월간 네비게이션 (Priority: P2)

사용자가 이전/다음 달 버튼을 통해 과거 월의 출석 기록을 탐색할 수 있다. 다음 달 버튼은 현재 월에서 비활성화되어 미래 달로 이동할 수 없다.

**Why this priority**: 과거 사용 이력을 확인하는 기능은 사용자의 장기적 동기 부여에 중요하지만, 기본 캘린더 조회 이후에 사용되는 보조 기능이다.

**Independent Test**: 이전 달 버튼 클릭 시 캘린더가 해당 월로 전환되는지, 다음 달 버튼으로 복귀 가능한지, 현재 월에서 다음 달 버튼이 비활성화되는지 검증.

**Acceptance Scenarios**:

1. **Given** 현재 월의 캘린더가 표시됨, **When** 이전 달 버튼을 클릭함, **Then** 이전 달 캘린더가 표시되고 월 표시가 변경됨
2. **Given** 과거 월의 캘린더가 표시됨, **When** 다음 달 버튼을 클릭함, **Then** 다음 달 캘린더가 표시됨
3. **Given** 현재 월의 캘린더가 표시됨, **When** 화면을 확인함, **Then** 다음 달 버튼이 비활성화 상태로 표시됨
4. **Given** 월이 변경됨, **When** 새로운 월의 캘린더가 로드됨, **Then** 해당 월의 출석 데이터가 화면에 반영됨

---

### User Story 3 - 동기부여 메시지 표시 (Priority: P3)

사용자가 출석 데이터와 함께 동기부여 메시지를 확인할 수 있다. 상단에는 제목과 함께 상승/하락 지표가 표시되고, 하단에는 캐릭터 기반 비유 메시지가 표시된다.

**Why this priority**: 사용자 경험을 풍부하게 하지만, 핵심 캘린더 기능 없이는 의미가 없는 보완 기능이다.

**Independent Test**: API 응답 데이터에 따라 title, content1(content2), subContent 메시지가 올바르게 표시되는지, 데이터가 없을 경우 기본 메시지가 표시되는지 검증.

**Acceptance Scenarios**:

1. **Given** 출석 데이터가 존재함, **When** 패널이 렌더링됨, **Then** 상단에 제목(title)과 함께 상승 아이콘+메시지(content1), 하락 아이콘+메시지(content2)가 표시됨
2. **Given** subContent 값이 캐릭터 키워드("뽀각거부기", "꾸부정거부기", "아기기린", "쑥쑥기린", "꽃꼿기린") 중 하나임, **When** 패널이 렌더링됨, **Then** 해당 키워드에 매핑된 비유 메시지가 표시됨
3. **Given** 출석 데이터가 아직 로드되지 않았거나 비어있음, **When** 패널이 렌더링됨, **Then** 기본 메시지("잘하고 있어요!", "당신은 매일 골든리트리버 한 마리를...")가 표시됨

---

### User Story 4 - 토글 스위치 및 인텐시티 슬라이더 표시 (Priority: P4)

패널 우측 상단에 월간/연간 토글 스위치와 사용 강도 범례(Less~More)가 표시된다. 현재는 월간 뷰만 지원하며 토글과 인텐시티 슬라이더는 UI만 표시된다.

**Why this priority**: 레거시와 동일한 UI 구조를 유지하기 위한 정적 UI 요소이며, 실제 동작은 포함되지 않는다.

**Independent Test**: 토글 스위치가 "월간/연간" 레이블과 함께 표시되는지, 인텐시티 범례가 5단계 노란색 바와 함께 표시되는지 검증.

**Acceptance Scenarios**:

1. **Given** 출석 현황 패널이 렌더링됨, **When** 패널 우측 상단을 확인함, **Then** "월간/연간" 토글 스위치가 표시됨
2. **Given** 출석 현황 패널이 렌더링됨, **When** 토글 스위치 하단을 확인함, **Then** "Less"~"More" 레이블과 함께 5단계 노란색 인텐시티 바가 표시됨

---

### Edge Cases

- 데이터가 없는 달의 캘린더: 모든 날짜가 회색 원 또는 미래 날짜 테두리로 표시됨
- API 호출 실패 시: 기본 메시지로 폴백되어 빈 화면이 아닌 의미 있는 콘텐츠가 표시됨
- 월 초(1일)에 접근할 때: 이전 달 이동이 정상 동작해야 함
- 윤년 2월: 29일까지 정상적으로 캘린더 셀이 표시되어야 함
- 사용 시간이 0분인 날: 데이터가 없는 것과 동일하게 회색 원으로 표시됨
- subContent가 알 수 없는 값인 경우: 원본 텍스트가 그대로 표시됨

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 패널은 4열 4행 그리드 레이아웃(첫 행 높이 57px, 나머지 행 균등 분할)으로 구성되어야 한다
- **FR-002**: 패널 좌측 상단에 "출석 현황" 제목과 현재 조회 중인 월(M월)이 표시되어야 한다
- **FR-003**: 패널에 7열 그리드 캘린더가 표시되어야 하며, 요일 헤더는 일~토 순서이다
- **FR-004**: 일요일 헤더 텍스트는 빨간색으로 구분되어야 한다
- **FR-005**: 캘린더의 각 날짜는 원형 도트로 표시되며, 사용 시간에 따라 5단계 노란색으로 구분된다 (0~1시간: 1단계, 1~2시간: 2단계, 2~3시간: 3단계, 3~4시간: 4단계, 4시간 이상: 5단계)
- **FR-006**: 사용 기록이 없는 날짜는 회색 원으로 표시되어야 한다
- **FR-007**: 오늘 날짜는 노란색 링(ring)으로 강조되어야 한다
- **FR-008**: 미래 날짜는 테두리만 있는 투명 원으로 표시되어야 한다
- **FR-009**: 이전/다음 달 네비게이션 버튼이 제공되어야 하며, 현재 월에서는 다음 달 버튼이 비활성화되어야 한다
- **FR-010**: 월간/연간 토글 스위치가 표시되어야 한다 (현재는 월간만 지원)
- **FR-011**: 사용 강도 범례(Less~More, 5단계 노란색 바)가 표시되어야 한다
- **FR-012**: 캘린더 우측에 정보 패널이 표시되어야 하며, 제목(title), 상승/하락 메시지(content1/content2), 동기부여 메시지(subContent)를 포함한다
- **FR-013**: subContent는 캐릭터 키워드에 매핑된 비유 메시지로 변환되어 표시되어야 한다
- **FR-014**: 데이터가 없는 경우 기본 메시지("잘하고 있어요!", "골든리트리버...")가 표시되어야 한다
- **FR-015**: 이관된 UI는 레거시 출석 현황 패널과 시각적으로 동일해야 한다

### Key Entities

- **출석 기록(Attendance)**: 날짜별 사용 시간(분 단위). 날짜(YYYY-MM-DD)를 키로, 사용 시간(분)을 값으로 하는 형태. 사용 시간은 5단계 레벨로 변환되어 캘린더 도트 색상에 반영됨
- **동기부여 메시지(Motivation Message)**: 출석 데이터에 포함된 제목(title), 긍정/부정 지표(content1, content2), 캐릭터 기반 비유 메시지(subContent). 캐릭터 키워드(뽀각거부기, 꾸부정거부기, 아기기린, 쑥쑥기린, 꽃꼿기린)에 따라 사전 정의된 메시지로 매핑됨

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 이관된 출석 현황 패널은 레거시와 시각적으로 동일하게 렌더링되어야 한다 (동일한 레이아웃, 색상, 간격, 폰트)
- **SC-002**: 캘린더의 모든 날짜 도트가 레거시와 동일한 크기(18x18px)와 색상 5단계로 표시되어야 한다
- **SC-003**: 월 네비게이션이 이전/다음 달 전환 시 지연 없이 반응해야 한다
- **SC-004**: 동기부여 메시지가 5개 캐릭터 키워드 모두에 대해 올바르게 매핑되어야 한다
- **SC-005**: 미래 달로의 네비게이션이 완전히 차단되어야 한다

## Assumptions

- 기존 백엔드 API(GET /dashboard/attendance)는 변경 없이 동일하게 사용 가능함
- 마이그레이션 대상 앱(Tauri)에서도 기존 API 통신 방식이 동일하게 적용 가능함
- 공유 UI 컴포넌트(PanelHeader, ToggleSwitch 등)는 이미 마이그레이션 프로젝트에 존재함
- 연간 뷰 기능은 현재 스펙에 포함되지 않으며, 향후 별도 작업으로 진행됨
- 레거시 컴포넌트명의 오타(AttendacePanel → AttendancePanel)는 이관 시 수정됨
- 기존 마이그레이션 폴더에 있는 AttendancePanel.tsx 파일을 기준으로 검증 및 보완 작업을 진행함
