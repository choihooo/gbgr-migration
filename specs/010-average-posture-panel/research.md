# Research: AveragePosturePanel 이관

**Date**: 2026-04-15
**Branch**: `010-average-posture-panel`

## R1: 레거시 기준 구현 선정

**Decision**: `src/renderer/src/features/dashboard/ui/AveragePosture/AveragePosturePanel.tsx`와 `levelConfig.ts`를 AveragePosturePanel의 유일한 기준 구현으로 사용한다.

**Rationale**:

- AveragePosturePanel은 레거시 메인 대시보드에서 실제로 렌더되는 첫 번째 패널이다.
- 패널 UI는 단순 카드 복제가 아니라 점수 구간에 따른 단계 정보와 시각 분기를 포함한다.
- 기준 파일을 단일 소스로 고정해야 점수 구간, 단계 이름, 기울기/하중 문구, 캐릭터 이미지가 흔들리지 않는다.

**Alternatives considered**:

- 현재 마이그레이션 구현을 기준으로 유지: 임시 도형 기반 대체 표현이 포함되어 있어 레거시 충실도 원칙에 어긋난다.
- 레거시 패널 구조만 참고하고 단계 정보는 새로 정리: 숫자 구간과 문구가 달라질 위험이 있다.

## R2: 단계 정보와 시각 분기 이관 방식

**Decision**: 평균 자세 점수의 단계 판정 규칙과 단계별 정보 세트는 레거시 정의를 그대로 포팅한다.

**Rationale**:

- AveragePosturePanel의 핵심 가치는 점수를 단계화해 사용자가 즉시 해석할 수 있게 만드는 데 있다.
- 레거시 `levelConfig.ts`에는 단계 이름, 목 평균 기울기, 예상 하중, 캐릭터 이미지가 함께 정의되어 있어 이 조합 전체가 사실상 하나의 도메인 규칙이다.
- 일부만 바꾸거나 재해석하면 레거시와 다른 결과가 화면에 나타난다.

**Alternatives considered**:

- 현재 마이그레이션의 6단계 로직 유지: 레거시는 5단계 기준이라 실제 표시 결과가 달라진다.
- 문구는 유지하고 이미지만 새로 제작: UI 스타일 변경 금지 원칙에 어긋난다.

## R3: 캐릭터 시각 요소 처리 방식

**Decision**: 단계별 캐릭터는 레거시 이미지 자산을 기준으로 동일하게 렌더링하며, 임시 도형 기반 플레이스홀더는 제거한다.

**Rationale**:

- 현재 마이그레이션 구현은 이미지 대신 추상 도형을 조합해 레거시 패널의 핵심 시각 요소를 대체하고 있다.
- AveragePosturePanel 우측 영역은 사용자가 단계 결과를 직관적으로 인식하는 대표 시각 요소라서 대체 표현이 허용되기 어렵다.
- 레거시 이미지 자산을 그대로 사용하면 가장 낮은 리스크로 동일성을 확보할 수 있다.

**Alternatives considered**:

- 우측 시각 영역을 임시 장식으로 유지: 레거시와의 시각 차이가 즉시 드러난다.
- CSS만으로 비슷한 캐릭터 실루엣 재현: 유지 비용이 높고 동일성 보장이 어렵다.

## R4: 배경 그라데이션 적용 기준

**Decision**: 단계가 낮은 구간과 높은 구간에 대한 배경 그라데이션 전환 기준은 레거시와 동일하게 유지한다.

**Rationale**:

- 배경 그라데이션은 AveragePosturePanel의 상태 인지를 보조하는 주요 시각 장치다.
- 레거시에서는 특정 단계 이하에서 거북이 계열 배경을, 그 외 단계에서 평균 점수 배경을 사용한다.
- 이 전환 규칙이 달라지면 같은 점수에서도 패널 인상이 달라진다.

**Alternatives considered**:

- 단계마다 모두 다른 배경을 도입: 레거시에 없는 해석이다.
- 항상 하나의 배경만 사용: 단계 시각 분기 정보가 사라진다.

## R5: 검증 방식

**Decision**: 핵심 검증은 레거시 대비 시각 비교로 수행하고, 자동 검증은 필요 시 구조 보존 수준으로 제한한다.

**Rationale**:

- 이 기능의 성공 기준은 스타일 개선이 아니라 레거시와의 시각 동일성이다.
- 점수 문구, 캐릭터 배치, 배경 표현, `Step` 위치는 DOM 존재만으로 충분히 검증되지 않는다.
- 수동 시각 비교가 가장 직접적이며 헌장의 UI 충실도 보존 원칙과도 맞다.

**Alternatives considered**:

- 상세 스타일 값까지 자동 테스트로 고정: 유지 비용이 높고 시각 동일성을 완전히 대체하지 못한다.
- 코드 리뷰만으로 검증: 실제 렌더 차이를 놓칠 가능성이 있다.

## 이관 결과 (구현 완료 후 작성)

**구현 요약**:

- `migration/src/features/main-panels/ui/AveragePosturePanel.tsx`를 레거시 구조 기준으로 재작성했다.
- 현재 마이그레이션 구현의 6단계 규칙을 제거하고, 레거시 5단계 규칙과 단계별 정보 세트를 복원했다.
- 우측 영역의 임시 도형 시각 요소를 제거하고, 레거시 캐릭터 이미지 자산을 `migration/src/assets/main/averagePosture/`로 이관해 사용하도록 변경했다.
- 배경 그라데이션 전환 기준과 하단 `Step` 표기를 레거시와 동일하게 맞췄다.

**배치 판단 근거**:

- `migration/src/features/dashboard/ui/LeftPanelArea.tsx`는 이미 레거시와 동일한 좌측 상단 슬롯에 `AveragePosturePanel`을 배치하고 있었다.
- 따라서 상위 레이아웃은 수정하지 않고, 패널 내부 구현만 레거시 기준으로 복원하는 것이 가장 안전했다.

**조회 훅 판단 근거**:

- `migration/src/entities/dashboard/model/use-dashboard-queries.ts`의 `useAverageScoreQuery`는 레거시 동일성 복원에 필요한 기본 조회 역할을 이미 충족하고 있었다.
- 이번 범위에서는 훅 자체를 수정하지 않고, 컴포넌트에서 레거시 점수/단계 규칙을 적용하는 것으로 충분했다.
