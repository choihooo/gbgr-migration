# Feature Specification: AveragePosturePanel 이관

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 평균 자세 점수 패널을 레거시와 동일하게 본다 (Priority: P1)

메인 대시보드를 사용하는 사용자는 AveragePosturePanel이 마이그레이션 앱에서도 레거시와 같은 카드 비율, 배경 그라데이션, 점수 문구, 단계 정보, 캐릭터 이미지 배치로 보여야 한다.

**Why this priority**: AveragePosturePanel은 레거시 메인 대시보드 좌측 상단에 가장 먼저 보이는 핵심 패널이다. 이 패널의 시각 동일성이 무너지면 대시보드 전체 이관 품질에 대한 신뢰가 바로 떨어진다.

**Independent Test**: 메인 대시보드에서 AveragePosturePanel만 확인해도 카드 배경, 점수 텍스트, 단계 표기, 캐릭터 이미지, 하단 Step 문구가 레거시와 동일한지 독립적으로 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 사용자가 마이그레이션 앱의 메인 대시보드에 진입했을 때, **When** AveragePosturePanel이 표시되면, **Then** 레거시와 동일한 둥근 카드 형태와 좌우 2단 구성, 하단 Step 표기가 보여야 한다.
2. **Given** 평균 자세 점수 데이터가 존재할 때, **When** 패널이 렌더링되면, **Then** 점수 값과 단계에 따른 명칭, 목 평균 기울기, 예상 하중, 캐릭터 이미지가 레거시와 같은 규칙으로 표시되어야 한다.
3. **Given** 단계가 낮은 구간과 높은 구간을 각각 확인할 때, **When** 패널 배경을 비교하면, **Then** 단계에 따른 배경 그라데이션 전환 규칙이 레거시와 동일해야 한다.
4. **Given** 사용자가 동일 해상도에서 레거시 화면과 마이그레이션 화면을 비교할 때, **When** AveragePosturePanel의 시각 요소를 확인하면, **Then** 육안 식별 가능한 구조 차이나 장식 차이가 없어야 한다.

---

### User Story 2 - 데이터 상태가 달라도 패널 구조를 안정적으로 본다 (Priority: P2)

사용자는 평균 자세 점수 데이터가 로딩 중이거나 값이 낮더라도, AveragePosturePanel의 기본 구조와 정보 위치가 흔들리지 않은 상태로 확인할 수 있어야 한다.

**Why this priority**: 이 패널은 조회 기반 UI이므로 데이터 상태 변화가 있어도 레이아웃이 무너지지 않아야 다른 패널과 함께 안정적으로 동작한다.

**Independent Test**: 로딩 상태와 기본 값 상태를 각각 확인해 점수 자리, 정보 문구 자리, 캐릭터 자리, Step 자리의 구조가 유지되는지 보면 독립적으로 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 평균 자세 점수 데이터를 아직 불러오는 중일 때, **When** 패널이 표시되면, **Then** 점수 영역은 레거시와 동일하게 플레이스홀더 형태로 유지되고 전체 레이아웃은 변하지 않아야 한다.
2. **Given** 평균 자세 점수가 가장 낮은 단계 또는 가장 높은 단계에 해당할 때, **When** 패널을 보면, **Then** 단계 이름, 설명 문구, 캐릭터 이미지, Step 숫자가 해당 단계에 맞게 일관되게 보이되 구조는 동일해야 한다.

---

### User Story 3 - 후속 대시보드 패널 이관의 기준으로 사용한다 (Priority: P3)

개발팀과 검증 담당자는 AveragePosturePanel 이관 결과를 기준으로, 조회 기반 시각 패널을 레거시 그대로 옮길 때 어떤 항목을 맞춰야 하는지 공통 기준으로 사용할 수 있어야 한다.

**Why this priority**: AveragePosturePanel은 데이터 조회와 단계별 시각 분기가 함께 있는 첫 번째 실제 대시보드 패널이므로, 이후 패널 이관에 재사용할 기준 사례가 된다.

**Independent Test**: 이관 완료 후 레거시와 마이그레이션 비교 기록만 있어도 카드 외형, 데이터 반영 방식, 시각 분기 기준을 팀이 동일하게 판단할 수 있으면 독립적으로 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** AveragePosturePanel 이관이 완료되었을 때, **When** 검증 담당자가 결과를 확인하면, **Then** 레거시 대비 동일성 여부를 판단할 수 있는 시각 비교 산출물이 있어야 한다.
2. **Given** 후속 대시보드 패널 이관 작업이 시작될 때, **When** 팀이 이 스펙을 참조하면, **Then** UI 개선 없이 레거시 그대로 이관한다는 기준과 검증 범위를 동일하게 이해할 수 있어야 한다.

### Edge Cases

- 평균 자세 점수 데이터가 아직 도착하지 않아도 카드 높이, 좌우 배치, 하단 Step 영역은 유지되어야 한다.
- 평균 자세 점수가 단계 경계값에 정확히 걸리는 경우에도 단계 이름, 설명 문구, 캐릭터 이미지 선택이 일관되어야 한다.
- 레거시와 마이그레이션의 공통 색상 토큰이 이미 존재하더라도, AveragePosturePanel의 그라데이션과 텍스트 대비는 레거시와 다르게 재해석해서는 안 된다.
- 현재 마이그레이션 구현처럼 임시 도형이나 대체 장식을 사용해 캐릭터 이미지를 대체해서는 안 된다.
- 메인 대시보드의 다른 패널이 아직 완전히 이관되지 않았더라도 AveragePosturePanel 단독 시각 결과는 검증 가능해야 한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 AveragePosturePanel을 레거시 메인 대시보드와 동일한 카드 크기 비율, 둥근 모서리, 내부 여백, 좌우 배치 구조로 제공해야 한다.
- **FR-002**: 시스템은 AveragePosturePanel 좌측 영역에 레거시와 동일한 "평균 자세 점수" 제목, 점수 값, 목 평균 기울기, 예상 하중 문구를 같은 순서와 같은 시각 위계로 표시해야 한다.
- **FR-003**: 시스템은 평균 자세 점수 값에 따라 레거시와 동일한 단계 판정 규칙을 적용해 단계 이름과 Step 숫자를 표시해야 한다.
- **FR-004**: 시스템은 단계에 따라 레거시와 동일한 캐릭터 이미지를 우측 영역에 표시해야 하며, 임의의 대체 일러스트나 도형으로 치환해서는 안 된다.
- **FR-005**: 시스템은 단계 구간에 따라 레거시와 동일한 배경 그라데이션 규칙을 적용해야 한다.
- **FR-006**: 시스템은 데이터 로딩 중에도 점수 영역과 정보 영역, 캐릭터 영역, Step 영역의 배치를 유지해야 한다.
- **FR-007**: 시스템은 AveragePosturePanel 이관 과정에서 새로운 문구, 추가 배지, 신규 인터랙션, 임의 장식 요소를 추가해서는 안 되며, UI 스타일을 변경하거나 개선된 해석을 도입해서도 안 된다.
- **FR-008**: 시스템은 AveragePosturePanel이 레거시 메인 대시보드의 실제 렌더 패널이라는 전제를 유지하며, 마이그레이션 메인 대시보드에서도 동일한 위치 맥락에서 검증 가능해야 한다.
- **FR-009**: 시스템은 AveragePosturePanel 이관 결과에 대해 레거시 대비 시각 동일성을 확인할 수 있는 비교 산출물을 남겨야 한다.

### Key Entities *(include if feature involves data)*

- **AveragePosturePanel 카드**: 메인 대시보드 좌측 상단에 표시되는 단일 패널 컨테이너로, 점수 정보 영역과 캐릭터 표시 영역을 함께 포함한다.
- **평균 자세 점수 상태**: 패널이 표시하는 핵심 수치 정보로, 점수 값에 따라 단계와 부가 설명이 달라지는 기준 상태다.
- **단계 정보 세트**: 단계 이름, 목 평균 기울기, 예상 하중, 캐릭터 이미지, Step 숫자를 묶어 표현하는 시각 정보 묶음이다.
- **배경 표현 상태**: 단계 구간에 따라 달라지는 패널 배경 그라데이션 상태다.
- **시각 비교 산출물**: 레거시와 마이그레이션 결과를 동일 조건에서 비교해 UI 동일성을 판단하는 캡처 또는 기록이다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 메인 대시보드 한 번의 진입으로 AveragePosturePanel의 제목, 점수, 단계 문구, 캐릭터 이미지, Step 표기 존재 여부를 모두 확인할 수 있어야 한다.
- **SC-002**: 동일 해상도 기준 레거시와 마이그레이션 AveragePosturePanel 비교 시 카드 구조, 배경, 텍스트 배치, 캐릭터 위치에서 육안 식별 가능한 차이가 없어야 한다.
- **SC-003**: 단계별로 최소 2개 이상의 서로 다른 상태를 비교했을 때, 단계 이름과 배경 표현, 캐릭터 선택 결과가 레거시와 동일해야 한다.
- **SC-004**: 현재 마이그레이션 구현에 존재하는 임시 도형 기반 대체 표현이 제거되고, 레거시 기준 시각 요소로 대체되어야 한다.

## Assumptions

- AveragePosturePanel의 기준 구현은 `src/renderer/src/features/dashboard/ui/AveragePosture/AveragePosturePanel.tsx`와 해당 단계 정보 정의를 따른다.
- AveragePosturePanel은 `docs/dashboard-panel-migration-analysis.md`에서 정의한 실제 메인 대시보드 렌더 패널 범위에 포함된다.
- 이번 스펙은 AveragePosturePanel 단독 이관 계획에 집중하며, 다른 패널의 데이터 연결이나 레이아웃 재설계는 범위 밖이다.
- 레거시와 동일성 판단은 동일 해상도 또는 동일 비율 조건에서의 시각 비교를 기본 검증 방식으로 사용한다.
- “UI를 똑같이 이관”의 의미는 구조, 비율, 문구 순서, 단계 규칙, 캐릭터 사용, 배경 표현을 유지하고 임의 개선을 하지 않는 것으로 해석한다.
